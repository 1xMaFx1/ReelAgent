# Текущая версия

ReelAgent Studio: свой текстовый промпт или следующий сценарий из очереди,
один запрос — один ролик. Локальная студия работает в Safari и запускается
через ReelAgent.app. На Mac только управление, просмотр и скачивание.

Рендер и бесплатная модель Qwen выполняются в GitHub Actions. Готовые файлы
хранятся в публичных Releases; письма о завершении включены в GitHub.
Расписания, автоматического скачивания и публикации в соцсети нет.

Исходники и служебные файлы на Mac находятся в «ReelAgent/Рабочие файлы»,
пользовательские видео — в соседней папке «Готовые ролики».
