# Проверка подключения

Недельный пакет расширен до 21 сценария; первый день — 28 сентября 2026.
Проверяйте фактические результаты установки в Actions и в панели «Статус агента».

Для ежедневного создания нужна переменная DAILY_ENABLED=true.
Для публикации дополнительно нужны подключённый профессиональный Instagram
@mateushstameska в Buffer, Secret BUFFER_API_KEY, variable BUFFER_CHANNEL_ID и
AUTO_PUBLISH_INSTAGRAM=true. Отсутствие этих данных не скрывается: MP4 создаётся,
а в метаданных отмечается «Instagram не подключён».

Первый реальный облачный запуск новой версии должен пройти проверку изображения,
голоса и скачивания. Успешный тест кода не подтверждает связь с Instagram.
