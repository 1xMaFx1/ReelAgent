# Текущая версия

Режим по кнопке: одна команда создаёт один следующий ролик. Нет расписания,
автопубликации и автоматического скачивания. Письма о завершении — через GitHub.

Для проверки откройте **Запустить ReelAgent.command**. Панель показывает готовые
выпуски из Releases и текущий облачный запуск. Кнопка «Скачать» сохраняет файлы
в «Готовые ролики» внутри проекта на рабочем столе.

История версий и результаты реальных проверок доступны в GitHub Actions.
