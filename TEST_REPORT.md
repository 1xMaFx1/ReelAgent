# Проверка поставки

Дата: 26 сентября 2026.

Проверено на Mac, Python 3.13.5:

- **32 pytest-теста прошли**: модели, JSON, конфигурация, субтитры, тайминги, SQLite, повторный запуск, независимость публикаций, защита от повторной отправки, восстановление Artifact, продолжение загрузки YouTube, логирование, команды компоновщика с музыкой и без.
- Ruff: ошибок нет.
- Импортированы все 34 модуля пакета app.
- CLI `python -m app.main --help` работает; пять требуемых команд присутствуют.
- Оба workflow-файла разобраны как YAML.
- Совместимость установленных зависимостей проверена `pip check`.
- **Реальный запрос к Edge TTS прошёл**: русский MP3 длительностью 5,38 секунды.

Что не проверено вживую:

- Gemini и Pexels: пользовательские API-ключи не предоставлены.
- Настоящий MP4: локальный рендер не запускался согласно требованию. Облачный FFmpeg smoke test включён в workflow Tests, но в этой сессии не запускался.
- Публикации YouTube, Instagram и Cloudinary: credentials не предоставлены, ничего не публиковалось.
- Docker build и запуск workflow на Python 3.12: файлы подготовлены, фактическая облачная проверка предстоит после загрузки репозитория.

Unit-тесты используют подмены сетевых ответов и FFmpeg. Их прохождение подтверждает логику, но не заменяет проверку первого облачного выпуска. Первый реальный MP4 появится после настройки ключей и запуска Daily Reel.
