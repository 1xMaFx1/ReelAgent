- Старый автоматический загрузчик Mac отключён. Workflow с расписанием, публикация в соцсети и устаревшая конфигурация Docker удалены.

Текущий поддерживаемый путь: лёгкая панель на Mac и рендер в GitHub Actions. Docker для него не нужен.
Unit-тесты проверяют выбор следующего сценария, повтор запроса, неполные Releases,
сборку подборок, сохранение файлов и защиту от повторного запуска.
Все 21 видео заранее не создавались. Работа зависит от доступности GitHub, NASA и Edge TTS.
