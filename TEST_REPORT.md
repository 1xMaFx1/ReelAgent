# Проверка поставки ReelAgent Studio

Дата: 28 сентября 2026.

- 56 локальных тестов прошли, Ruff и проверка форматирования — без ошибок.
- GitHub CI проверяет Python 3.12 и создаёт настоящий тестовый MP4 через FFmpeg.
- Папка на Mac упорядочена: ReelAgent.app, «Рабочие файлы», «Готовые ролики». Скрытые настройки, Git и прежние материалы сохранены.
- ReelAgent.app запущен через Finder; студия открылась в Safari.
- Промпт отправляется через API приложения в workflow отдельным строковым аргументом; вставки shell-команд не исполняются. Один запрос создаёт один выпуск.
- Генерация нового сценария бесплатной моделью Qwen2.5:3b в GitHub Actions проверена реальными выпусками вне космической темы.
- При проверке исправлены хэштеги в озвучке, поисковые запросы не на английском, обрывы фраз и загрузка изображений с thumb.wikimedia.org. Для этих случаев добавлены тесты.
- Проверено скачивание настоящего MP4 и сопутствующих файлов в «Готовые ролики». Кнопка скачивания проверена в Safari. Сервер просмотра возвращает корректный HTTP 206 для перемотки MP4.
- Реальное свободное фото «Cat into the box.jpg» успешно найдено и скачано через Wikimedia Commons. Используются Public domain / CC0; при нехватке подходящих фотографий создаётся графический фон.
- Промежуточные тестовые видео перенесены в «Рабочие файлы/data/test-videos», их Releases переведены в черновики без удаления.
- Уведомления GitHub Actions по почте включены; фактическая доставка в почтовый ящик не проверялась.

Свободная небольшая модель может допускать стилистические и фактические ошибки;
перед публикацией нужно просмотреть ролик. Поддержка любых тем означает создание
сценария и монтажа, а не фотореалистичную генерацию видеосцен по тексту.
