# Одна кнопка — один готовый ролик

1. На рабочем столе откройте папку **ReelAgent** и дважды нажмите **Запустить ReelAgent.command**.
2. В Safari нажмите **Создать следующий ролик**. Агент возьмёт следующий сценарий из очереди.
3. Можно выключить Mac: видео создаётся на GitHub. Письмо GitHub сообщит о завершении или ошибке.
4. Откройте панель снова и нажмите **Скачать** рядом с нужным роликом.

Файлы появятся в **Рабочий стол → ReelAgent → Готовые ролики → номер выпуска**:
MP4, «Название.txt», «Описание.txt», субтитры и сведения об источниках.
На самой странице GitHub также можно скачать MP4; браузер сохранит его в свою
обычную папку загрузок. Кнопка нашей панели сохраняет именно в папку проекта.

Расписания нет. Автопубликации нет. Скачивание начинается только по вашей команде.
К аккаунтам Instagram и YouTube подключаться не нужно. Buffer, ключи соцсетей
и платные языковые модели для этого режима не используются.

Подготовлен 21 сценарий: по три разных выпуска на каждую из семи тем Claude.
После последнего агент остановится. Для продолжения передайте новый пакет
промптов в чат — сценарии нужно подготовить и проверить перед добавлением.
Наличие старых дат и номеров вариантов внутри JSON — совместимость идентификаторов,
а не расписание: очередь не зависит от сегодняшней даты и времени.

Готовые ролики хранятся в публичных GitHub Releases, как вы разрешили ранее.
Они остаются доступны, даже если Mac был выключен; автоматического удаления нет.
Очередь узнаёт завершённые выпуски по полному комплекту файлов в Releases.
Повтор после ошибки не пропускает незавершённый сценарий. Повтор того же
запроса после успешной сборки не создаёт дополнительный ролик.

Письма о завершении включаются в GitHub → Settings → Notifications → Actions → Email.
«Only notify for failed workflows» должно быть выключено, иначе писем о готовности
не будет. Это настройка аккаунта GitHub; она относится и к другим запускаемым вами workflow.
Доставка письма зависит от GitHub и почты; состояние всегда видно в панели и Actions.
