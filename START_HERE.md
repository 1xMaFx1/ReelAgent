# ReelAgent Studio

1. На рабочем столе откройте **ReelAgent → ReelAgent.app**. Студия откроется в Safari.
2. Вставьте обычный текст в поле **«О чём будет твой рилс?»**: тему, пожелания к подаче или промпт Claude. Можно писать на любые темы, не только про космос. От 10 до 6000 символов.
3. Нажмите **«Создать 1 рилс»**. Если поле пустое, агент возьмёт следующий подготовленный сценарий из прежней очереди.
4. После запуска Mac можно выключить: сценарий, озвучка и монтаж выполняются на GitHub. Для нового промпта загружается бесплатная языковая модель, поэтому ожидание дольше, чем для готового сценария.
5. GitHub пришлёт письмо о завершении или ошибке. В студии есть статус и ссылка **«Посмотреть процесс»**.
6. Нажмите **«Скачать видео»** в карточке. Видео и сопутствующие файлы окажутся в **ReelAgent → Готовые ролики → номер выпуска**. После скачивания видео можно посмотреть прямо в студии.

## Папка проекта

- **ReelAgent.app** — запуск студии.
- **Готовые ролики** — ваши видео, названия, описания, субтитры и источники.
- **Рабочие файлы** — исходники, настройки, временные данные, прежние рабочие материалы. Не перемещайте отдельные файлы из этой папки.

Ничего из прежних рабочих материалов не удалено. Всю папку ReelAgent можно перенести целиком.

## Что получается по промпту

Модель Qwen работает внутри облачного запуска, без платного API и ключа Claude.
Она пишет русский сценарий, короткое название, ключевые слова и хэштеги.
Видеоряд — монтаж свободных фотографий Wikimedia Commons, а при отсутствии
подходящих материалов — графический фон с озвучкой и субтитрами. Готовая очередь
космических роликов использует NASA. Это не генератор фотореалистичных движущихся
сцен из текста. Проверьте факты и качество перед публикацией.

Промпт и результат попадают в публичный GitHub-проект; не вставляйте секреты
или личные данные. Текст в поле сохраняется на этом компьютере между открытиями.
Скачивание только по кнопке. Расписания, рекламы и автопубликации нет.

Письма: GitHub → Settings → Notifications → Actions → Email, без фильтра
«Only notify for failed workflows». Настройка уже включена; доставка зависит
от GitHub и почтового сервиса. Эта настройка относится и к другим вашим workflow.
