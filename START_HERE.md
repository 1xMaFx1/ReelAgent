# С чего начать

1. Прочитайте раздел «Быстрый путь к первому ролику» в `README.md`.
2. Получите два ключа: Gemini и Pexels.
3. Создайте GitHub-репозиторий и загрузите туда проект, включая скрытую папку `.github`.
4. Добавьте `GEMINI_API_KEY` и `PEXELS_API_KEY` в GitHub Secrets.
5. Откройте Actions → Daily Reel → Run workflow → generate.
6. Скачайте Artifact `reel-…`: это ваш MP4, metadata.json и субтитры.

На Mac монтаж заблокирован. Здесь можно запускать тесты и проверять API. Все команды и настройка YouTube/Instagram подробно описаны в README.

Для первого ролика YouTube, Instagram и Cloudinary не нужны. Автопубликация по умолчанию выключена.
