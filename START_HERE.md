## Как увидеть работу

Дважды нажмите «Статус агента.command». В Safari откроется панель с состоянием
облаччного запуска, фактом включения расписания, временем проверки, следующим
выпуском, оставшимися заданиями и сохранёнными видео. Получатель обновляет её
примерно каждые пять минут. Если данные старше десяти минут, панель предупреждает.
Результаты: «Рабочий стол → ReelAgent → Готовые ролики → ГГГГ-ММ-ДД-час».
Статус «запланировано» отличается от «опубликовано»: последнее требует ответа Buffer.
Живой журнал: https://github.com/1xMaFx1/ReelAgent/actions.
Очередь Instagram доступна также в Buffer.

## Расписание и публикация

Облачные запуски: 07:17, 11:17, 16:17. Ролик после создания передаётся Buffer,
который планирует автоматическую публикацию в ближайший целевой час.
Через семь минут после каждого целевого часа облако проверяет результат публикации.
При пропущенном сроке MP4 сохраняется, но внеплановый поздний пост не создаётся.
GitHub, Buffer и Instagram могут задерживаться: точность до минуты не гарантируется.

Аккаунт: https://www.instagram.com/mateushstameska/.
Нужны бесплатный Buffer, подключение Instagram через Professional → Instagram Login,
API-ключ Buffer в GitHub Secret BUFFER_API_KEY и идентификатор канала в BUFFER_CHANNEL_ID.
Facebook и карта не нужны. Разрешения Buffer подтверждает владелец аккаунта.
AUTO_PUBLISH_INSTAGRAM включается только после проверки подключения.
Создание само по себе не означает, что автопубликация уже подключена.

Готовые MP4, с разрешения владельца, сохраняются публично в GitHub Releases:
https://github.com/1xMaFx1/ReelAgent/releases. Там они доступны до публикации.
Описание в Instagram — только ключевые слова и хэштеги. Заголовок остаётся в видео
и отдельном файле. YouTube выключен; реклама не добавляется.

Для создания и публикации Mac не нужен. Он нужен для скачивания в локальную папку.
Если Mac выключен, MP4 остаётся в Releases. Рабочее облачное состояние и архивы
для автоматического скачивания хранятся сутки; после длинного простоя может
понадобиться восстановление. MP4 из Releases не удаляются автоматически.

«Запустить ReelAgent.command» создаёт ближайший выпуск как превью без отправки
в Instagram. Это не отменяет его последующей отправки по включённому расписанию.
