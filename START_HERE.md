# ReelAgent: ежедневный выпуск в 08:00

Канал: https://www.youtube.com/channel/UCr74LNUyePqX4CLS9sI5IPg
Часовой пояс: Europe/Simferopol (UTC+3). Публикация — в 08:00.
Облачная подготовка начинается в 05:17; Buffer получает готовый ролик заранее.

Названия новых роликов — короткие и цепляющие, до 55 символов, без ложных обещаний.
Описание содержит только ключевые слова и хэштеги. Реклама пока не добавляется.
Первый уже загруженный ролик владелец оформляет самостоятельно; агент его не меняет.

## Что требуется один раз

1. Бесплатный Buffer с подключённым именно этим YouTube-каналом и API key.
2. Бесплатный Pexels API key для видеоряда.
3. Бесплатный Cloudinary: Cloud Name, API Key, API Secret — для передачи MP4 в Buffer.
4. Двойной щелчок по «Настроить ключи.command»: ввод скрыт, значения попадут в GitHub Secrets.
   Пароли и ключи не надо присылать в чат. Связанный канал Buffer определяется автоматически.

На всех сервисах оставьте Free, не добавляйте банковскую карту и платный trial.
Модель Qwen работает только на облачном сервере GitHub: отдельного аккаунта и ключа нет.

После проверки подключений и первого сквозного выпуска: EPISODE_FILE удалить,
DAILY_ENABLED=true, AUTO_PUBLISH_YOUTUBE=true, DRY_RUN=false. До этой проверки ежедневная
публикация не считается запущенной. Код расписания сам по себе не заменяет авторизацию.

Повторный запуск в тот же день не создаёт второй ролик. Готовые файлы скачиваются кнопкой
«Запустить ReelAgent.command». Cloudinary использует семь сменяемых слотов, чтобы старые
исходники не накапливались. В Buffer одновременно ожидает публикации один новый ролик.

Если сервер опоздал и до 08:00 осталось менее пяти минут, видео сохраняется, но не публикуется
позже указанного времени. Сбои внешних сервисов возможны; точное время нельзя гарантировать
при их недоступности. Ошибка публикации отмечается как ошибка облачного запуска.

Облачные файлы хранятся ограниченное время; скачанные файлы на Mac остаются.
