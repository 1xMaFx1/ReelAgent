# Ежедневное создание видео

Папка: **Рабочий стол → ReelAgent → Готовые ролики → дата**.
Внутри: reel.mp4, превью, субтитры, «Название.txt», «Описание.txt».
Название короткое и цепляющее; описание — только ключевые слова и хэштеги.
Автопубликация выключена. Реклама не добавляется без отдельного указания.

Облако запускается ежедневно в 04:17 и повторно в 06:17 (Europe/Simferopol, UTC+3).
Цель — готовое видео до 08:00. Повторная попытка не создаёт второй готовый ролик за день.
Mac проверяет результат каждые 5 минут после входа в систему.
Для появления файла к 08:00 Mac должен быть включён, не спать и иметь интернет.
Если компьютер спал, скачивание произойдёт после пробуждения. Бесплатные сервисы
могут задерживаться или давать сбои, поэтому абсолютной гарантии времени нет.

Ручной запуск: дважды нажмите «Запустить ReelAgent.command».
Никаких новых регистраций, карт и ключей не требуется. GitHub уже подключён.
Qwen через Ollama и FFmpeg работают в облаке; на Mac идёт только скачивание.
Фактическая основа и изображения — NASA, русский голос — Edge TTS.

Пауза ежедневных выпусков: GitHub Actions → Variables → DAILY_ENABLED=false.
Включение: DAILY_ENABLED=true. Получатель Mac: com.reelagent.download.
Облачный архив хранится 7 дней; скачанные файлы остаются на Mac.
Ошибки сборки: GitHub → Actions → Daily Reel. Журнал скачивания: .local/receiver.log.
При утрате всей облачной истории программа останавливается до восстановления базы,
чтобы не повторять темы. Первый черновик на YouTube агент не меняет.
Источник будущей рекламы: ADVERTISING.md. Никаких заявок рекламодателям не отправлено.
