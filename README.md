# ReelAgent

Инструкции: [START_HERE.md](START_HERE.md). Три разных ролика по одному дневному
промпту, 21 подготовленный сценарий, часы публикации 08/12/17 UTC+3.

Python 3.12, FFmpeg, NASA, Edge TTS. Монтаж только на облачном Linux;
Mac — небольшой получатель и локальная HTML-панель. Claude и платные LLM API
в текущем режиме не вызываются. Изображения NASA анимируются, озвучиваются
и монтируются; это не фотореалистичная генерация видеосцен нейросетью.

План: prompts/current-week.json. Хэш задания закрепляется в SQLite за слотом
YYYY-MM-DD-HH. Повторы используют готовый MP4. Кадры каждого выпуска сохраняются
для итоговой подборки своего временного слота. Если кадры потеряны, подборка
останавливается и не заменяет их случайными изображениями.

Публикация: Buffer GraphQL API, automatic + customScheduled. Проверяется, что
канал — разрешённый @mateushstameska. Перед createPost workflow сохраняет намерение
в облачный артефакт; неоднозначный результат не повторяется автоматически.
Это защищает от дублей ценой ручной проверки неопределённого ответа.
После публикации выполняется отдельное чтение статуса Buffer.

MP4 размещаются в разрешённых пользователем публичных GitHub Releases.
API-ключ остаётся в GitHub Secrets; на Mac он не нужен. GitHub token не пересылается
на сторонние хосты при скачивании артефактов. Исходники не содержат паролей.

Проверки: `pytest tests`, `ruff check .`, реальный Linux smoke render в CI.
Сетевые сбои, задержка GitHub cron, исчерпание бесплатных квот и отзыв разрешений
могут остановить выпуск. Бесплатный план не даёт гарантии времени публикации.
