# ReelAgent

**Открыть ReelAgent.app → вставить промпт → создать один рилс → скачать.**

Русские вертикальные ролики по обычному текстовому промпту: бесплатная модель Qwen
готовит сценарий в облаке, Edge TTS озвучивает, FFmpeg собирает фотографии и графику
с субтитрами. Поддерживаются любые темы. Без подходящих свободных фотографий
используется явно обозначенный графический фон. Это монтаж, а не text-to-video модель.
Старая очередь из 21 подготовленного сценария также доступна — оставьте поле пустым.

## Запуск

На настроенном Mac: **ReelAgent.app**. Откроется студия в Safari.
В основной папке находятся приложение, «Рабочие файлы» и «Готовые ролики».
Для организации нового checkout: `python3 scripts/install_desktop.py /путь/к/ReelAgent`.
Из исходников панель также запускается через `python3 -m scripts.desktop`.
На другом компьютере нужны Python 3.12+ и официальный GitHub CLI с входом в
аккаунт, имеющий доступ к запуску этого репозитория. Отредактируйте launcher.json
при использовании своего форка. Локальная панель использует стандартную библиотеку
Python; ключи соцсетей, API Claude и фоновый запуск на Mac не нужны.

В GitHub можно напрямую открыть **Actions → Create Reel → Run workflow**.
В поле prompt можно передать свой текст, или оставить его пустым для очереди.
Каждый запуск создаёт ровно один ролик. В текущем пакете 21 сценарий;
первые 18 — самостоятельные выпуски, последние три — подборки предыдущих кадров.

## Архитектура

- Панель: локальный сервер на 127.0.0.1:8766, кнопки создания и скачивания.
- Облако: ручной workflow create-reel.yml, стандартный Ubuntu runner, Python и FFmpeg.
- Очередь: prompts/current-week.json; имена старых дат служат только идентификаторами.
- Хранилище: публичные Releases. Полный комплект MP4, recap.mp4 и metadata.json
  служит подтверждением готовности. История не зависит от суточных артефактов.
- Письма: встроенные уведомления GitHub Actions для запущенных владельцем сборок.
- На Mac ничего не рендерится; готовое скачивается только по нажатию.

Расписание и модули автопубликации удалены. Ни один workflow не отправляет ролики
в соцсети. Ключи остаются в Keychain GitHub CLI, не передаются локальной странице.
Локальные действия защищены проверкой Host, Origin и случайным токеном; сервер
слушает только loopback. Перезапуск запроса определяется по request_id, а рабочая
очередь GitHub сериализована для защиты от конфликтов между сборками.

## Разработка и проверка

`pip install -r requirements-dev.txt`, затем `ruff check app scripts tests` и `pytest`.
54 теста проверяют также разбор своего промпта, перенос папки и графический fallback.
CI дополнительно создаёт тестовый MP4 с настоящим FFmpeg на Linux.
Тесты покрывают выбор следующего задания, повтор запроса, незавершённые загрузки,
ошибки рендера, сборку подборки, сохранение MP4 и защиту от повторного нажатия.

Платные API не используются. Наличие интернета и доступность GitHub, NASA и
голосового сервиса необходимы; при сбое готовые выпуски сохраняются в Releases.
Изменение использованного сценария меняет его хэш и считается новым выпуском.

Модель: [Ollama](https://ollama.com/download/linux), Qwen2.5:3b. Фотографии для своих
промптов: [Wikimedia Imageinfo API](https://www.mediawiki.org/wiki/API:Imageinfo),
только материалы с лицензией Public domain / CC0. Источники сохраняются в metadata.json.
